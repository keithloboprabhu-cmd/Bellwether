# Tactical console redesign contract

The user's five attached references set the direction: black operational workspace,
compact utility rail, bounded data panels and dense terminal tables. The current
request supersedes the earlier spacious Instrument composition and static-motion
preference. The Python financial engine, source provenance and company mode remain.

- Palette: OLED #000000, contained surface #050505, amber #D5A64B, text #E8E5DC,
  muted #A39D8F, green #6BCB9E and red #FF7770. Gold hairlines define panel boundaries.
- Type: locally hosted Source Code Pro for command controls, data and headings;
  Source Sans for longer methodology/source descriptions. No external font calls.
- Layout: 56px collapsible utility rail; thin system bar; four ordered command
  modules; compact model totals; Field + exposure plot + company inspector; scrollable
  telemetry grid. Initial state is an actual configuration/universe view, with no
  promotional hero or fabricated live feed.
- Flow: industry unlocks policy, policy unlocks numeric parameters, valid inputs
  unlock execution. Shared URLs restore completed controls. Edits leave the applied
  result labeled until execution. Company editing uses short stages and financial
  subgroups instead of a single long form.
- Data: show projected EPS, revenue, model net income and implied price alongside
  their absolute and percentage changes. Model NI and reported EPS are distinct
  bases. Historical EPS sparklines come from committed annual filings; custom
  companies without history get an explicit unavailable state. Ranges are scenario
  bounds, never statistical confidence intervals. Exposure scatter axes identify the
  actual configured exposure and units; company selection links all views.
- Motion: brief initialization radar scan, execution sweep, real elapsed request
  ticker, fast panel/pill transitions and chart reveals. No simulated market ticks,
  false progress percentages or runtime LLM calls. Reduced-motion preference and an
  in-app motion toggle disable nonessential animation. No new dependency.
- Finish: check progressive control locks, failed/repeated execution, zero/undefined
  denominators, chart/table selection, profile flow, desktop/mobile layout, keyboard
  focus and automated accessibility. Capture the finished interface.
